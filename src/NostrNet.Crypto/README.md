# NostrNet.Crypto

Cryptographic primitives for the [NostrNet](https://github.com/Galaxoid-Labs/NostrNet)
.NET 10 Nostr client library: RFC 8439 ChaCha20, NIP-44 v2 payload
encryption, NIP-17 private direct messages, NIP-59 gift wrap, NIP-51
encrypted lists.

Most apps don't reference this package directly — install
[NostrNet.Client](https://www.nuget.org/packages/NostrNet.Client) which
pulls Crypto in transitively.

See the main project [README](https://github.com/Galaxoid-Labs/NostrNet)
for usage.
